What is Genesis 0.7?
Genesis 0.7 extends the generator with a visual language for how geometry is drawn and how generations are coloured. Strokes remain independent from geometry, while colour modes determine the colour assigned to each generated figure. The goal is more visual expression without turning Genesis into a general-purpose graphics editor.

STROKES · 0.7.1

Stroke controls only the way generated geometry is rendered. It does not modify the Primitive or the generation geometry.
  • Solid — continuous line.
  • Dashed — repeated dash pattern.
  • Dotted — repeated dot pattern.
  • Proportional — available for Dashed and Dotted. When enabled, the pattern grows with the Genesis generation rather than remaining fixed.

COLORS · 0.7.2

  • Gradient — continuous progression from Start to End.
  • Alternate — consecutive generations alternate between Start and End.
  • Three Colors — uses Start, Middle and End. Middle occupies a narrow visual band centred on Palette Center; the rest of the progression remains continuous.
  • Palette Center — controls the visual centre of Gradient and Three Colors.

MONOCHROME · 0.7.3

Color selects one colour for the whole generation.
  • Progressive OFF — every generated figure uses the selected colour.
  • Progressive ON — the generation progresses from white toward the selected colour.

SPECTRUM · 0.7.4

Spectrum traverses the full visible colour spectrum continuously, beginning at red and passing through the primary and intermediate spectral colours before returning to red. The first visible cycle is deliberately extended beyond the strict fit field so it reads as a complete rainbow; subsequent generations repeat the cycle as you move through the generated universe.

Spectrum has no additional colour controls. The spectrum is a property of the generation itself, not a user-selected palette.

SUPERPOSITION

ACCUMULATE lets a new generation coexist with the current universe. LAYERS shows accumulated generations. UNDO removes the most recent layer. CLEAR removes the accumulated universe without changing current parameter values.

PERSISTENCE · CONFIG

EXPORT CONFIG saves the current Genesis configuration. IMPORT CONFIG restores a previously exported configuration and regenerates the universe. Custom Primitives and supported presentation state remain part of the configuration workflow.

CREATE · YOUR OWN SHAPES

Genesis 0.7 retains the complete 0.6 Primitive workflow: canonical space [-1,+1] × [-1,+1], LINE and ARC segments, precision targeting, MOVE, and local persistence of Custom Primitives.

EXPLORE · OBSERVER

NEAR ↔ FAR changes your view through the completed generated universe.

TRAVEL · GO vs ENGAGE

  • GO — travel normally toward the deepest, primordial part of the generated universe.
  • ENGAGE — enter WARP and continue into the infinite mathematical sequence.
WARP EXPERIENCE
When WARP begins, the Bridge disappears so the universe fills the screen. Press G to bring it back. If accumulated layers exist, ENGAGE warns before entering WARP because the current superposition may be discarded.

SPACE · BACKGROUND

  • Space background displays the bundled space-background.jpg behind the generated universe.
  • The background is decorative and does not participate in geometry or generation logic.

HELP & SHORTCUTS

Ctrl/Cmd+S — export the current configuration.
Ctrl/Cmd+Z — undo the last generation; in the Primitive Editor, undo the last point.
H — open this manual.
G — show/hide the Bridge controls; in WARP, the first press restores the Bridge.

RESET

RESET restores the Genesis 0.7 welcome configuration: the refined Genesis G Custom Primitive, Spectrum, Solid stroke, the agreed generation settings and the Space background.

The 0.7 idea
Genesis 0.7 does not change what Genesis is. It gives the same generative geometry a richer visual language through Strokes & Colors. The default welcome demonstrates that language without requiring any setup.
