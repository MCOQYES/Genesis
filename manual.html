What is Genesis?
Genesis creates a universe from a sequence of generated geometric figures. You choose the geometry, growth, rotation and colour behaviour, explore the resulting universe, and — if you dare — ENGAGE WARP to travel beyond its primordial boundary into an infinite mathematical continuation.

CREATE · SHAPES

  • Shape — Triangle, Square, Pentagon, Hexagon, Octagon, Circle, Line, X, Cross, Parallel Vertical, Parallel Horizontal, Arc, Angle, Star or Radial.
  • Angle — available only for Arc and Angle. Controls the geometry angle from 0° to 360°.
  • Points — available only for Star. Controls the number of star points from 5 to 12.
  • Rays — available only for Radial. Controls the number of rays from 3 to 72.

CREATE · COLOUR

  • Start / End — choose the beginning and ending colours.
  • Color Mode · Gradient — the normal Genesis colour progression from Start to End across the generated figures.
  • Color Mode · Alternate — consecutive generated figures alternate between Start and End instead of using the gradient.
  • Palette Center — controls the visual centre of the Gradient transition. It has no visual effect in Alternate mode.

GENERATE · BEHAVIOUR

  • Mode — Static, Forward, Repeat or Breath.
  • Delay — controls the time between generated figures in animated modes.
  • GENERATE — builds the universe from the current settings.

EXPLORE · OBSERVER

NEAR ↔ FAR
The Observer slider changes your view through the completed generated universe. Use it to inspect the geometry before travelling.

TRAVEL · GO vs ENGAGE

  • GO — travel normally toward the deepest, primordial part of the generated universe. STOP lets you interrupt travel and inspect it.
  • ENGAGE — enter WARP. The primordial point becomes a landmark rather than a final destination, and the journey continues into the infinite mathematical sequence.
WARP EXPERIENCE
When WARP begins, the Bridge disappears so the universe fills the screen. Press G or the floating G button to bring the Bridge back; press G again to hide it.

Genesis colors in WARP is optional. OFF gives a clean monochrome WARP; ON alternates white with the selected arrival colour.

SPACE · BACKGROUND

  • Space background — displays the bundled space-background.jpg as a fixed visual layer behind the generated universe.
  • The background is OFF by default. It does not participate in the geometry or generation logic.

HELP & SHORTCUTS

H — open this manual in a new tab.
G — show or hide the Bridge controls; in WARP, the first press restores the Bridge.

RESET

RESET restores the default Genesis configuration and generates it again.
