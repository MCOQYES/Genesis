What is Genesis 0.6?
Genesis 0.6 is the branch in which the generator crosses from using only predefined geometry to working with user-defined primordial geometry. You can create, refine, precisely place, curve and move your own Primitive, then keep it available for future sessions.

PRIMITIVE MODEL · FOUNDATION

A Primitive is one or more ordered 2D paths in canonical space [-1,+1] × [-1,+1]. Each path may be open or closed and may contain straight LINE segments or simple ARC segments.
  • Canonical space — normalized 2D coordinates, centered on (0,0).
  • Canonical scale — the Primitive definition is independent of screen pixels, viewport size and output resolution.
  • Multiple paths — a Primitive can contain more than one independent path.
  • LINE + ARC — mixed segment types are supported in the same Primitive.

CREATE · PRIMITIVE EDITOR

  • CREATE PRIMITIVE opens the editor.
  • LINE creates straight segments by placing points.
  • ARC creates an arc with three clicks: CENTER → START → END. The END click defines the final angle; Genesis keeps the arc on the radius established by START.
  • NEW PATH begins an independent path inside the same Primitive.
  • CLOSE PATH closes the current path with a final straight connection.
  • Undo / Ctrl-Z removes the most recent point/segment while editing.
  • Remove Path removes the selected path.
  • USE PRIMITIVE registers the edited geometry as Custom.

PRECISION · TARGETING

The editor uses the canonical coordinate system [-1,+1] × [-1,+1]. Rulers, live X/Y coordinates, grid placement and point targets are visual aids only; they do not change the Primitive model.

MOVE · PATH

Select a path and drag its line to move the whole path. Genesis keeps the path inside the canonical bounds and preserves its geometry. Point dragging remains available when you want to edit individual points instead.

SUPERPOSITION

ACCUMULATE lets a new generation coexist with the current universe. LAYERS shows accumulated generations. UNDO removes the most recent layer. CLEAR removes the accumulated universe without changing current parameter values.

PERSISTENCE · 0.6.7

Custom Primitive is persisted locally in the browser after it is used. Reopening Genesis can recover the saved Custom geometry.

EXPORT CONFIG saves the complete current configuration, including the Custom Primitive and superposition layers.

IMPORT CONFIG restores the saved configuration and its Custom Primitive.

Genesis deliberately does not add a separate Shape Library or extra save/load buttons. Persistence belongs to the existing configuration workflow.

GENERATE · BEHAVIOUR

  • Mode — Static, Forward, Repeat or Breath.
  • Delay — controls timing between generated figures in animated modes.
  • GENERATE — builds the universe from current settings.

EXPLORE · OBSERVER

NEAR ↔ FAR changes your view through the completed generated universe.

TRAVEL · GO vs ENGAGE

  • GO — travel normally toward the deepest, primordial part of the generated universe.
  • ENGAGE — enter WARP and continue into the infinite mathematical sequence.
WARP EXPERIENCE
When WARP begins, the Bridge disappears so the universe fills the screen. Press G to bring it back. If accumulated layers exist, ENGAGE warns before entering WARP because the current superposition may be discarded.

SPACE · BACKGROUND

  • Space background displays the bundled space-background.jpg behind the generated universe.
  • The background is decorative and does not participate in geometry or generation logic.

HELP & SHORTCUTS

Ctrl/Cmd+S — export the current configuration.
Ctrl/Cmd+Z — undo the last generation; in the Primitive Editor, undo the last point.
H — open this manual.
G — show/hide the Bridge controls; in WARP, the first press restores the Bridge.

RESET

RESET restores the agreed Genesis 0.6 welcome configuration: the Genesis G Custom Primitive, its initial visual settings and the Space background.

The 0.6 idea
Genesis 0.6 is not a new editor. It is the moment in which Genesis can work with your own shapes.
